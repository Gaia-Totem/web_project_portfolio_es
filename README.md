# web_project_portfolio_es

Proyecto del Sprint 4: Portafolio
Descripción del proyecto:
El proyecto consiste en crear un portafolio personal como desarrollador web, planificando todo desde cero, sin instrucciones paso a paso.
Construyendo una tarjeta de presentación digital propia, donde muestre mis habilidades y proyectos (como web_project_coffeeshop_es).
TECNOLOGIAS Y TÉCNICAS utilizadas:
-Figma como guía de diseño (brief).
Se utiliza MEDIA QUERYS para crear un diseño responsivo que se vea bien en los siguientes dispositivos:
resoluciones pequeñas de hasta 320 px
📱 Móvil (hasta 767px)
💻 Tableta (hasta 1023px)
🖥️ Escritorio (más de 1023px).
